ทำไม Windows ถึงขึ้น “Windows protected your PC”?

หน้าต่างนี้เป็นระบบ SmartScreen ของ Windows ที่เตือนทุกครั้งเมื่อเปิดโปรแกรมที่ยังไม่มีลายเซ็นดิจิทัลจากผู้เผยแพร่ที่ Windows รู้จัก และยังไม่มีคนโหลดไปรันมากพอ เกมนี้ทำโดยนักพัฒนาอิสระและยังไม่ได้ซื้อใบรับรองรับรอง (ซึ่งมีค่าใช้จ่ายรายปี) คำเตือนนี้เป็นเรื่องของชื่อเสียงไฟล์ ไม่ได้แปลว่าตรวจพบมัลแวร์

ถ้าคุณไม่สบายใจ ไม่ต้องติดตั้ง ใช้ขั้นตอนตรวจสอบไฟล์ด้านล่างก่อนได้

Windows protected your PC

App: KaDuekBanRang-Setup.exe
Run anyway Don’t run
หลังจากนั้นทำตามตัวติดตั้งปกติ ไม่ต้องใช้สิทธิ์แอดมิน

ใช้ Windows 11 แล้วโดนบล็อกเลย ไม่มีปุ่ม Run anyway? เป็นเพราะโหมด Smart App Control ที่บล็อกโปรแกรมที่ไม่ได้เซ็นและยังไม่มี reputation ถ้าไม่อยากปิดโหมดนี้ อาจต้องเล่นบนเครื่องอื่น หรือเล่นบนมือถือ Android แทน

ติดตั้งบน Android แล้วมีข้อความเตือน?

ไฟล์ .apk นี้แจกจากเว็บโดยตรง ไม่ได้มาจาก Google Play Android จึงเตือนทุกครั้งที่ติดตั้งแอปจากแหล่งภายนอก ข้อความที่อาจเจอ (หน้าตาต่างกันตามยี่ห้อและเวอร์ชันของเครื่อง) และวิธีผ่าน:

1. “ไฟล์ประเภทนี้อาจเป็นอันตราย”
ขึ้นตอนดาวน์โหลดใน Chrome (This type of file can harm your device)

กด เก็บไว้ / Keep เพื่อให้ไฟล์โหลดต่อ

2. “ไม่อนุญาตให้ติดตั้งแอปที่ไม่รู้จัก”
Install unknown apps

กด ตั้งค่า / Settings แล้วเปิด “อนุญาตจากแหล่งนี้ / Allow from this source” ให้แอปที่คุณใช้เปิดไฟล์ (เช่น Chrome หรือ ไฟล์ของฉัน) จากนั้นกดย้อนกลับแล้วกดติดตั้ง ติดตั้งเสร็จแล้วปิดสิทธิ์นี้ได้

3. “Play Protect บล็อกแอปนี้ / ยังไม่เคยสแกน”
Blocked by Play Protect, App not scanned

กด รายละเอียดเพิ่มเติม / More details แล้วเลือก ติดตั้งต่อไป / Install anyway (หรือเลือกสแกนแอปก่อนก็ได้) ไม่ต้องปิด Play Protect ทั้งระบบ

ติดตั้งไม่ได้เลย ไม่มีปุ่มให้ไปต่อ? ตามที่มีการรายงาน ตั้งแต่ปลายเดือนกันยายน 2026 เครื่อง Android ที่ผ่านการรับรองของ Google ในไทย (และอีกไม่กี่ประเทศ) เริ่มบล็อกแอปจากนักพัฒนาที่ยังไม่ผ่านการยืนยันตัวตนกับ Google เกมนี้ทำโดยนักพัฒนาอิสระที่ยังไม่ได้ลงทะเบียน จึงอาจโดนบล็อกบนเครื่องของคุณ ซึ่งเป็นกฎของระบบ ไม่ได้แปลว่าไฟล์มีมัลแวร์ ถ้าเจอแบบนี้ ลองเปิดเล่นผ่านเบราว์เซอร์แทนที่ หน้าเล่นในเบราว์เซอร์ (ใน Chrome เลือก “เพิ่มลงในหน้าจอหลัก” จะได้ไอคอนเต็มจอ)

แอปนี้ไม่ขอสิทธิ์ใด ๆ ทั้งอินเทอร์เน็ต กล้อง ไมโครโฟน และที่เก็บข้อมูล เล่นแบบออฟไลน์ ตรวจได้ที่ ตั้งค่า → แอป → กะดึกบ้านร้าง → สิทธิ์ ต้องใช้ Android 5.0 ขึ้นไป แนะนำให้เล่นแนวนอนและใส่หูฟัง

ตรวจสอบว่าไฟล์ปลอดภัย

1. เทียบค่า SHA256 เปิด PowerShell ในโฟลเดอร์ที่โหลดไฟล์ แล้วรัน

Get-FileHash .\KaDuekBanRang-Setup.exe -Algorithm SHA256

ค่าที่ได้ต้องตรงกับค่านี้ ถ้าไม่ตรง อย่าติดตั้ง และโหลดใหม่จากหน้านี้เท่านั้น

ไฟล์ .apk (Android) มีค่า SHA256 ดังนี้ เทียบได้ด้วยคำสั่งเดียวกันบนคอม หรือแอปตรวจ hash บนมือถือ

2. ดูผลสแกนไวรัส

3. ติดตั้งแบบปลอดภัยต่อเครื่อง ตัวติดตั้งไม่ขอสิทธิ์แอดมิน ลงในโฟลเดอร์ของคุณเอง ถอนการติดตั้งได้จาก Settings → Apps

คำถามที่พบบ่อย

ทำไมไม่เซ็นรับรองไฟล์ให้หายเตือน?

ใบรับรองสำหรับเซ็นโปรแกรมมีค่าใช้จ่ายรายปี และบริการราคาถูกบางตัวจำกัดประเทศ แม้เซ็นแล้วคำเตือนก็ไม่หายทันที ต้องสะสมคนโหลดก่อน ตอนนี้จึงใช้วิธีเปิดเผยค่า SHA256 และผลสแกนแทน

ถอนการติดตั้งยังไง?

Windows: Settings → Apps → Installed apps → กะดึกบ้านร้าง → Uninstall · Android: ตั้งค่า → แอป → กะดึกบ้านร้าง → ถอนการติดตั้ง

ต้องต่ออินเทอร์เน็ตไหม?

ไม่ต้อง ภาพและเสียงทั้งหมดอยู่ในตัวเกม
